Under the hood

Backend

Django 5 handling routing, authentication, and the ORM, organized by vertical slice so each feature owns its views, templates, and assets.

Database

Supabase PostgreSQL, with schema managed entirely through Django migrations — a custom user model plus per-feature profile and settings tables.

Document parsing

Python libraries for text extraction from standard PDF and Word files. Complex or creative resume layouts are intentionally out of scope.

NLP extraction

A pretrained NER model tags skills, education, and certifications from extracted text. No custom-trained model — accuracy varies with resume formatting.

Scoring logic

Rule-based keyword and criteria matching, not semantic embedding similarity or ML prediction. Chosen deliberately to keep scope achievable in one semester.

Fairness approach

Rule-based anonymization hides identifying fields during review. No ML bias audit trained on historical hiring data — a stated limitation, not an oversight.
